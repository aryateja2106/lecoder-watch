Can you see my code?

No. There is no relay of ours; the phone talks straight to your machine. Every line is redacted first, so ghp_ABCD leaves as ghp_••••••[902dd5].

Does it work when I'm out?

Only if your phone can reach the machine: the same network, or your own Tailscale tailnet. There is no relay to fall back on.

What do I install?

One line per machine: curl -fsSL https://lesearch.ai/install.sh | sh. It lands in ~/.mesh, runs under launchd or systemd, survives reboot, and never runs as root.

Do I need an account?

No. Pairing is an eight-character code your own machine prints, single use, ten minutes. The only account is optional, so we can reply to a problem report.
