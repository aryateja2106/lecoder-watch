# Reference projects (read before building the same thing)

Clones live under `references/external/repos/` (gitignored — `git clone --depth 1` them back
with the URLs here). One line each on what to take, and what not to.

| Project | What it is | Take | Leave |
|---|---|---|---|
| [hsandhu/mobilecode](https://github.com/hsandhu/mobilecode) | opencode fork that detects an iOS/Android project, runs `serve-sim` / `serve-avd`, and embeds the live simulator stream next to the agent session; a `device_run` tool lets the agent build, launch, read the build error and log tail itself | the **device pane** shape (Start/Stop/Run/Stop-run over HTTP: `/api/device-preview/*`), the agent-driven run tool, "opening the pane never starts a build" — this is what our Apps tab + `mesh apps install` want to grow into for agents that build native apps | its Electron desktop, Metro/Expo plumbing |
| [EvanBacon/serve-sim](https://github.com/EvanBacon/serve-sim) | streams an iOS Simulator to a browser (Node 20+) | the stream approach for a "watch the agent's app run" view on the phone | — |
| [andrisgauracs/Apple-Watch-Edge-AI](https://github.com/andrisgauracs/Apple-Watch-Edge-AI) | upstream llama.cpp cross-compiled for **watchOS** (`arm64_32` + `arm64` slices), a Series 6 running a quantized model on-device with a tool-calling setup | `tools/build_llamacpp.sh` — the exact flags: `-DCMAKE_SYSTEM_NAME=watchOS -DCMAKE_OSX_ARCHITECTURES=arm64_32 -DCMAKE_C_FLAGS=-D_DARWIN_C_SOURCE -DGGML_METAL=OFF -DLLAMA_SUBPROCESS=OFF …`, and why (ggml's arch check is `STREQUAL`, so `arm64_32` silently falls to the generic path); `WatchLLM/LlamaCppEngine.swift` + `Bridge/` for the Swift side | its demo model choice — Needle fits the wrist better for tool calls |
| [danveloper/flash-moe](https://github.com/danveloper/flash-moe) | MoE experts streamed from flash into Metal on the Mac (`metal_infer`, `repack_experts.py`, `expert_index.json`), with measured progress | the expert-index + repack layout if we ever front a big MoE on the Mac ourselves; compare against edge0's SSD pool (`docs/adr-2026-09-22-local-brains-and-streaming-moe.md`) | building it for launch |
| [cactus-compute/needle](https://github.com/cactus-compute/needle) (Needle 2) | 8–29 MB Simple-Attention-Network model for **tool calls, structured extraction and embeddings** on phones, wearables, MCUs; ships `libneedle.a` for ios-arm64, ios-sim-arm64, watchos-arm64, macos-arm64, linux-arm64 (`references/external/models/needle2/`) | the on-device brain: our `intent/mesh-tools.json` already scores 26/28 wrist phrases with it on the Mac; the watch/iPhone static libs are the next slice (`docs/adr-2026-09-22-on-device-brain.md`) | fine-tuning before the tool set is stable |
| [vercel-labs/fx](https://github.com/vercel-labs/fx) ([fx.sh](https://fx.sh)) | Zig CLI coding agent, one binary, model-agnostic (AI Gateway default), `fx ask --json`, ACP server, `libfx` for embedding | a lightweight harness for the picker (`AGENT_CLIS`), `fx ask --json` for headless one-shots, its permission modes (`/permissions ask|auto|full-access`) — see `docs/agents/harnesses.md` | its default `auto` mode when a phone must approve: use `ask` |
| [Edge0-AI/Edge0](https://github.com/Edge0-AI/Edge0) | SSD-streamed MoE serving on Apple Silicon (`references/external/repos/edge0`, our tool-call patch in `references/patches/`) | `/brain` candidate on the Mac; measured 11 tok/s, tool call in 3.8 s with the patch | 35B on a 24 GB Mac |
| [TypeSafe Jev](https://vercel.com/ai-gateway/models/jev) (`typesafe-ai/jev` on the AI Gateway) | an **evaluation** model: `Choice` / `Score` / `Noul` over a state, 70–500 ms, cannot generate text | daemon-side decisions: is this event actionable, how risky is this command (`risk.ts`), which tool does a phrase mean, transcript → task list; needs a card on the Vercel team | using it as an agent's brain — it is not a chat model |
| [Desert Ant models](https://desertant.com/models/) | one small on-device model per task: Voz (speech, 10 min in 2 s on iPhone), Align, Ear/Tongue (language id), Redact (PII), Schemer (typed JSON), Gist, Title, Uhm, Who, Clear | the transcript pipeline for meetings (Voz → Who → Schemer → tasks), PII redaction before anything leaves the device, language id for Telugu/Hindi/English mixes | anything cloud-shaped |

How to use them: `codegraph`/`graphify` do not index `references/external`; open the file the row names. When a reference changes what we build, write the ADR first and cite the file.
