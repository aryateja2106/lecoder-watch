From token field → named identities

The single plaintext SecureField becomes SessionListCard rows: multiple SSH (user + key/password) and VNC (user + password) identities grouped per machine.

Per-machine binding picker

Each machine has a Bindings group that chooses which stored identity its SSH and VNC connections use — blue value = the active selection.

Reveal-on-hold, never copied

Secrets render masked with a "hold to reveal" chip. No pasteboard copy path, killing the old free-copy leak.

Status colors stay semantic

Green = active/online identity, orange = expired VNC password / needs re-auth, grey = idle. Blue is the only non-status accent, used for the active binding.

Native sheet to add

Grabber, centered title, circular blue Done check. Scan-QR (import from meshd) or Manual grouped-inset fields. Footer reassures it lands in the Keychain.
