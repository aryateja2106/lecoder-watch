Toggle one field to invalid to see the inline error state & pending chip.

  • Native sheet vocabulary. Grabber, centered “Add Machine” title, trailing circular blue Done check pill — replaces the raw push-to-Settings stack.
  • One accent, used for action. Blue marks the QR button, Done pill, and credential picker only. Surfaces stay monochrome (#0A0B0D / #1E2125).
  • Green is status, never decoration. The inline check and “Reachable · auth OK” chip appear only after a successful probe.
  • Orange / red speak failure. Pending shows an orange “Resolving…” chip; a duplicate or empty host turns the field error red with an inline reason.
  • No plaintext secrets. The SecureField + “Copy token” footgun is replaced by a Keychain-backed credential picker.
  • QR-first onboarding. A 54pt primary button lets a non-technical user pair a machine without typing a tailnet host or port.
