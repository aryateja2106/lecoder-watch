One readable output line + state pill, then trust-tiered presets. Danger is red and walled off.

Key design choices

Glance before grid Top third is read-only: latest line, a single state pill (running / waiting / idle), and pane awareness (2/3). You decide before you touch a key.
Trust-tiered keys Monitor (neutral, read-only) → Send (blue, keystrokes) → Danger. Color encodes consequence, so a fat-finger never escalates by accident.
Danger is walled off Stop / Kill sit below a red divider at the very bottom of the scroll — destructive actions are red and physically separated, never adjacent to Continue.
Lively terminal glance The one output card mirrors real ANSI terminal output (green/orange/red are the program's own status, not chrome). The shell around it stays strictly monochrome with a neutral cursor.
No keyboard, just intent Ad-hoc input is Voice + Scribble only — native watch entry. No cramped custom keyboard; the watch sends intent, the Mac does the typing.
