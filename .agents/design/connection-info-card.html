StatusPill, not decoration. The green check beside arya-pi means the session is live — green is reserved for working/ok, never used as an accent.
Read-vs-act split is structural. Facts (Desktop Size → Connection Type, App Version) carry a right-aligned value and no chevron — they aren't tappable. Only settings get a chevron.
Disclosure = action. Picture Quality & Interaction are blue-tap targets that open a picker; the chevron is the affordance contract.
Numbers are monospaced. Resolution, speed, protocol and version use SF Mono so digits align and read as machine data, not prose.
