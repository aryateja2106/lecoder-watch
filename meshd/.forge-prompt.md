# PRINCIPAL'S ACTUAL REQUEST (authoritative spec — implement exactly)

STACK: bun + TypeScript ONLY. Never npm/npx/node. Cross-platform: macOS (arm64) AND Linux (Pi aarch64, dataflow x86_64). Detect `process.platform`.

AUTH: every request requires `Authorization: Bearer <token>` where token = env `MESHD_TOKEN`. Missing/wrong → 401. Bind `0.0.0.0` on env `MESHD_PORT` (default 8899) — tailnet-private but token-gated. If `MESHD_TOKEN` is unset/empty at startup, refuse to start with a clear fatal error (never run an open, unauthenticated server).

ENDPOINTS (all JSON unless noted):

- `GET /health` → `{ok:true, host, platform, arch, uptimeSec, meshdVersion:"0.1.0"}`

- `GET /stats` → normalized cross-OS system stats:
  `{host, platform, cpuPct (0-100, overall), load:[1m,5m,15m], mem:{usedMB,totalMB,pct}, swap:{usedMB,totalMB}, disk:{path:"/",usedGB,totalGB,pct}, topProcs:[{pid,cmd,cpuPct,memMB,memPct}] (top 8 by cpu desc), agentsCount}`
  - macOS: derive `cpuPct` from `top -l 2 -n 0` (use the 2nd sample's CPU usage line) or fall back to `ps -A -o pcpu`; mem from `vm_stat` + `sysctl hw.memsize`; swap from `sysctl vm.swapusage`; disk from `df -k /`; load from `os.loadavg()` (or `sysctl -n vm.loadavg`); procs from `ps -A -o pid,pcpu,rss,comm -r | head`.
  - Linux: `cpuPct` from two reads of `/proc/stat` ~200ms apart (compute busy delta / total delta * 100); mem + swap from `/proc/meminfo` (MemTotal, MemAvailable, SwapTotal, SwapFree); load from `/proc/loadavg` (or `os.loadavg()`); disk from `df -k /`; procs from `ps -eo pid,pcpu,rss,comm --sort=-pcpu | head`.
  - Use `os` module where clean. Prefer `Bun.spawn`/`Bun.$` for shelling. Return numbers, not strings; round sensibly. `agentsCount` = number of rmux sessions (reuse the /agents collector; if rmux missing, 0).
  - `memMB` for procs is derived from RSS (rss is in KB from ps) → MB. `memPct` = procMemMB / totalMB * 100.

- `GET /agents` → rmux sessions: `[{name, windows:int, createdISO, attached:bool, cwd?, agentType?}]`. Source: `rmux list-sessions -F '#{session_name}|#{session_windows}|#{session_created}|#{session_attached}'` (parse pipe-delimited; `created` is unix SECONDS → ISO; `attached` is "1"/"0" or a count → bool). For `agentType`, best-effort: `rmux list-panes -t <name> -F '#{pane_current_command}'` and map (claude→Claude, codex→Codex, node/bun→Node, bash/zsh→shell; otherwise leave undefined or the raw command). `cwd` best-effort via `rmux list-panes -t <name> -F '#{pane_current_path}'` if available; omit if not. If rmux missing or no server running, return `[]` (200, not 500).

- `GET /agents/:name/output?lines=N` (default 80) → `{name, lines:string[]}` from `rmux capture-pane -p -t <name>` (return last N lines). 404 if no such session (check `rmux has-session -t <name>` first). Sanitize/validate `name`.

- `POST /agents/:name/send` body `{text?:string, key?:"enter"|"ctrl-c"|"up"|"down"}` → inject input.
  - `text` → `rmux send-keys -t <name> -H -- <hexBytes...>` where hexBytes = each UTF-8 byte of text as a 2-char lowercase hex string, EACH AS A SEPARATE ARGV element (this is the proven rmux-bridge pattern: `Array.from(new TextEncoder().encode(text), b => b.toString(16).padStart(2,"0"))`, then spread into argv after `--`).
  - `key:"enter"` → `send-keys -t <name> Enter`; `"ctrl-c"` → `send-keys -t <name> C-c`; `"up"` → `send-keys -t <name> Up`; `"down"` → `send-keys -t <name> Down`.
  - If both text and key are given, send text first then key. If neither, 400. Return `{ok:true}`. 404 if session missing.

- `POST /agents/new` body `{name, cwd?, cmd?}` → `rmux new-session -d -s <name>` plus `-c <cwd>` if cwd, plus `<cmd>` as the final arg if cmd. Sanitize `name` to `[A-Za-z0-9._-]+` (reject otherwise → 400). 409 if a session with that name already exists (`rmux has-session`). Return `{ok:true, name}`.

- `GET /usage` → macOS ONLY: read `~/Library/Application Support/com.sunstory.openusage/usage-api-cache.json` (build path from `os.homedir()`), normalize to:
  `{fetchedAt, providers:[{id, displayName, plan, limits:[{label, usedPct, resetsAtISO, periodDurationMs}], today?, yesterday?, last30?, topModels?:[{label,pct}]}]}`
  Cache shape (REAL — verified): top-level `{version, snapshots:{<id>:{providerId, displayName, plan, lines:[...], fetchedAt}}}`. Each line is one of:
    - `{type:"progress", label, used, limit, format:{kind:"percent"|"count"|"dollars", suffix?}, resetsAt, periodDurationMs}` → map to a `limit` entry. `usedPct` = `used/limit*100` ONLY when `format.kind === "percent"`, else `null`. `resetsAtISO` = `resetsAt` (already ISO or null). Carry `periodDurationMs` (may be null).
    - `{type:"text", label, value}` → if label is "Today" → `today=value`; "Yesterday" → `yesterday=value`; "Last 30 Days" → `last30=value`; if label looks like a MODEL ID (contains `-` AND label not in the known-set below) → push `{label, pct}` to `topModels` where `pct` = parseFloat of value (strip `%`). Other text labels (e.g. "Account", "Session" as text) → ignore.
    - `{type:"barChart", ...}` → ignore.
  - KNOWN-SET of non-model text labels to exclude from topModels: `Today`, `Yesterday`, `Last 30 Days`, `Account`, `Session`, `Weekly`, `Spark`, `Spark Weekly`, `Credits`, `Usage Trend`, `Plan`. (Match case-insensitively; the guard is "contains `-` AND not in known-set".) Note real model labels look like `gpt-5.5`, `gpt-5.3-codex-spark`, `claude-opus-4-7`, `claude-sonnet-4-5-20250929` — all contain `-`.
  - Provider-level `fetchedAt` for the top response: use the newest snapshot `fetchedAt`, or the file mtime if absent. Each provider keeps its own snapshot fields.
  - Include ALL providers present in snapshots (codex, claude, gemini, antigravity, cursor, ...). Order is not critical but Claude and Codex must both appear.
  - On Linux (or if the cache file does not exist): return `{providers:[]}` with HTTP 200. If the file exists but is malformed JSON, return `{providers:[]}` and log a warning — do not 500.
