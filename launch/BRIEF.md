# Brand, landing, pitch, and demo brief

Status: active launch brief. This aligns the current product; it is not authorization to invent product UI or alter public claims.

## Brand hierarchy

**LeSearch AI** is the company. **LeSearch Mesh** is the product. **Less Search. More Agents.** is the company tagline.

The promise is: **agents keep working without keeping a person pinned to a terminal.** A task runs on a machine the customer owns, asks for a human decision, reaches the right device, and continues after an intentional answer.

## Current product truth

Lead with what the current beta proves:

- Pair owned Mac or Linux machines through the Mesh daemon.
- See machines, agent sessions, terminal output, and attention states on iPhone and Apple Watch.
- Send deliberate input, including risk-labelled confirmation, and use the iPhone remote screen/trackpad where the host supports it.
- Receive APNs attention notifications after the user installs the local hook.
- Operate over a reachable LAN or VPN already in use.

Do not lead with generic remote desktop, promise use from every network, or show a future surface as shipped.

## Landing story

| Beat | Visitor shift | Proof |
| --- | --- | --- |
| Recognition | "My agent keeps working while I leave the desk." | A real, calm owned-machine task state. |
| Tension | "One unanswered question pauses useful work." | A legible needs-you state. |
| Peak | "The task reaches me, not the other way around." | The same state hands off from Mac to Watch, then iPhone when more room is needed. |
| Proof | "I can inspect and answer deliberately." | Current watch terminal, machine list, phone terminal, and supported remote-control captures. |
| Boundary | "My machine remains in charge." | Plain-language local-first explanation, including APNs and reachable-network caveats. |
| Commitment | "I know the next step." | One beta action, consistently labelled. |

The signature move is the **attention handoff**: a running task becomes a Watch-sized question, receives an intentional response, then visibly continues. Make that one short sticky CSS sequence only after the static version is clear. No continuous 3D flight, WebGL dependency, fake dashboard, or generated terminal content is needed.

If motion is used, ship a poster first, an authored mobile composition, and a complete `prefers-reduced-motion` static state. All copy remains HTML and every product state comes from a current redacted capture.

## Demo spine

Capture a reproducible 90–120 second video on a spare daemon:

1. Start a harmless long-running agent task on an owned machine.
2. Show it stop for a real question.
3. Receive and read the attention state on Watch or iPhone.
4. Answer deliberately, then show the session continue.
5. Show a second real surface only if it proves a distinct capability.
6. End on the honest local-first boundary and a single beta action.

Physical Watch/iPhone notification and interaction behavior needs a human check; build/simulator evidence is not enough.

## Ten-slide pitch spine

1. LeSearch AI / LeSearch Mesh: agents keep working while people keep moving.
2. The problem: long-running agents create attention debt.
3. Why now: agent work is more capable and more asynchronous.
4. Product: agent-aware supervision on machines the customer owns.
5. Live proof: the attention handoff.
6. Wedge: real terminal on the wrist plus agent feed and supported screen control.
7. Business-model hypotheses: paid multi-machine/pro features and later team plans, pending price tests.
8. Go-to-market: qualified design partners first, then repeatable demo-led acquisition.
9. Metrics: pairing activation, attention-loop completion, retained supervising users, and privacy-safe reliability.
10. Raise: $1M to prove retention, paid demand, onboarding, and product hardening. Do not present a fixed valuation without current traction and counsel.
