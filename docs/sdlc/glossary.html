Words, in plain English

Every word this site uses, in one sentence, with a link to the place in our own repo where you can see it.

AGENTS.md and INDEX.md
Each folder has an AGENTS.md, a short hand-written brief on what the folder is for and how to prove a change, and big folders also get an INDEX.md, a file list that a script writes and nobody edits by hand. See it: scripts/folder-index.py (writes the INDEX files) and intents/AGENTS.md (an example brief)
Artifact
The one document each stage writes down and commits, so the next stage reads it instead of relying on anyone's memory. See it: intents/README.md
Beta App Review
Apple's check of a test build before it may reach testers outside your own team; until it approves a build, people with the public link do not get it, because uploading is not publishing. See it: docs/updating.md
Block
One piece of work in our ordered list, with who acts on it and the proof that says it is finished. See it: the blocks page and docs/sdlc/BLOCKS.md
Branch protection (ruleset)
A GitHub setting that makes the main line refuse any change that did not come through an approved pull request; it was off on this repo when checked on 2026-09-27. See it: docs/factory/CONTRACT.md
Charter
The file where you, the human, write down how much freedom agents get and when they must stop; when checked on 2026-09-27 it still said CHARTER_STATUS: incomplete. See it: docs/factory/CHARTER.md
Check (self-check)
A small script named check-something that tests one fact about the repo and prints either "ok" or what is wrong; scripts/check-all.sh runs all of them. See it: scripts/INDEX.md
CI (continuous integration)
GitHub running our checks automatically every time a change is pushed. See it: .github/workflows/ci.yml
Complication
The small live element on the watch face; ours shows how many agents are waiting, which session, and the question it is asking. See it: WatchWidgets/WatchGlanceWidget.swift
Control band
The normal range of a number, such as how often CI fails, worked out from its own history, so only unusual movement asks for attention. See it: Stages 5–6, the template
Daemon (meshd)
The background program that runs on each of your machines and that the phone and the watch talk to. See it: install/payload/meshd/
DORA metrics
Four standard delivery numbers: how often you release, how long a change takes to reach users, how often a release breaks, and how fast you recover. See it: Stages 5–6, what we would measure
Draft pull request
A pull request marked "not ready to accept"; the factory only ever opens these, so a human always makes the final call. See it: docs/factory/CONTRACT.md
Eval
A saved test task with a known right answer, re-run often to catch something getting worse; the only one in our repo on 2026-09-27 tests how the product's own voice model turns a phrase into an action, not how coding agents behave. See it: intent/cases.jsonl
Factory
This repo's name for agents taking one GitHub issue at a time, doing it, proving it, and opening a draft pull request. See it: docs/factory/CONTRACT.md
Gate
An automatic check that must say green before work moves on; its last line, starting FACTORY_GATES:, is the verdict. See it: .claude/scripts/gates.sh
Heartbeat (telemetry)
The one anonymous message a day the daemon may send out, holding only a version, a platform and a few counters, never anything you typed or saw; it can be turned off. See it: install/payload/meshd/telemetry.ts
Hook
A small script the agent tool runs automatically before an action, used to block dangerous actions whatever the agent intends. See it: .claude/hooks/block-merge.sh
Intent
A short note in your own words saying what problem you want solved, for whom, and what "done" looks like, written before anyone designs anything. See it: intents/TEMPLATE.md
intent/ versus intents/
Two folders with nearly the same name: intent/ (singular) holds test phrases for the product's local voice model, and intents/ (plural) is where your Stage 1 intents live. See it: intent/cases.jsonl and intents/
Live Activity
The live card on the iPhone Lock Screen, the Dynamic Island and the watch Smart Stack that shows which agent is waiting on you. See it: MeshWatchWidgets/
Load-bearing path
A file or folder so important (sign-in, policy, CI) that no agent may change it without a human reading the change. See it: docs/factory/CHARTER.md
Merge
Accepting a pull request so its change becomes part of the main line; in this repo agents are blocked from doing it. See it: .claude/hooks/block-merge.sh
mesh (the command line)
The command you type on a machine to pair a phone, upgrade the daemon or start an agent. See it: install/payload/bin/mesh
Non-goal
Something we have decided on purpose not to build, such as a cloud relay or an account system, which outranks any new idea. See it: ROADMAP.md
OpenSpec
The folder where bigger product changes are written up as proposals and requirements before anyone builds them. See it: openspec/
Pairing and token
Pairing brings a phone onto your machines with a short code instead of a long secret, and the token is that secret, which the daemon checks on every request and refuses when it is missing. See it: install/payload/meshd/pair.ts and install/payload/meshd/auth.ts
Plan
The list of files that will change, in what order, what could go wrong, and how we will prove it worked, written before any code. See it: openspec/changes/reach-my-mac-from-anywhere/tasks.md (our nearest file)
Proof (status line)
The fact written into every "Where we are" line on this site, which a script tests so the line cannot say "done" while the repo says otherwise. See it: docs/sdlc/AGENTS.md
Publish ledger
The file that lists what was actually released, where every line is evidence produced by running something, not by describing it. See it: PUBLISHED.md, read by scripts/check-published.sh
Pull request (PR)
A proposed change shown as a before and after, which a human reads and then accepts ("merges") or rejects. See it: docs/factory/CONTRACT.md
Redaction
Blanking out secrets, such as passwords and keys that agents print, from every piece of text before it leaves your Mac for a phone, a watch or Apple's push servers. See it: install/payload/meshd/redact.ts
Relay (phone for the watch)
When the watch cannot reach a machine directly, the phone passes its requests along and brings the answers back. See it: Watch/
Rollback
Putting the previous working version back; on 2026-09-27 there was no one-command rollback, but mesh upgrade keeps the old daemon in a backups folder instead of deleting it. See it: install/payload/bin/mesh
Runbook
A pre-written, pre-approved step-by-step fix for a known kind of problem, for example "roll back the daemon". See it: Stages 5–6, the template
Serialized file
A shared file that only one agent may edit at a time, because two agents changing it at once would break each other's work. See it: Stage 3, serialized files
σ (sigma)
The usual amount a number wiggles; "2σ" means twice the usual wiggle, which is rare enough to look into. See it: Stages 5–6, the template
Skill
A written instruction pack an agent loads for one kind of task, such as a security review; it advises and does not enforce. See it: .claude/skills/INDEX.md
Source of truth
The one file or place that wins when two documents disagree about the same thing. See it: index.md (the repo's start-here map)
Spec
The agreed description of what will be built and how it should look and behave, written from an intent and checked against your rules. See it: openspec/changes/reach-my-mac-from-anywhere/proposal.md
Subagent
A second agent started with a clean memory to do one job, such as checking the first agent's work without trusting its story. See it: .claude/agents/factory-verifier.md
Surface
One of the things a customer actually touches, such as the iPhone app, the watch app or the command line. See it: the product map
TestFlight
Apple's app for installing test builds; it is how new versions of our iPhone app reach testers, and the watch app rides along inside it. See it: docs/updating.md
Worktree
A second copy of the project folder on disk, on its own branch, so two agents can work at once without overwriting each other. See it: docs/sdlc/references/orca.md
