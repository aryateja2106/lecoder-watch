# docs/sdlc/ — the lifecycle teaching site: the AI-native playbook explained with this repo's own files, plus the ordered blocks

**Read first:** [README.md](README.md) (what this folder is), [index.html](index.html) (the map of all six stages), then [BLOCKS.md](BLOCKS.md) (the ordered work). Pages are for Arya first; every file a page names is a link you can open.
**Surface:** docs
**Serialized (one agent at a time):** `sdlc.css`, and the `<header class="top">` nav block, which is copied identically into all ten pages; change it on every page in one commit. `BLOCKS.md` (block ids are shared by every page).
**Prove a change:**
- `sh scripts/check-sdlc-site.sh` — every relative `href`/`src` in `docs/sdlc/*.html` resolves on disk, and every `B-nn` in `BLOCKS.md` appears on a page. Run it before every commit that touches this folder.
- `INDEX.md` here is generated: `python3 scripts/folder-index.py`, then `sh scripts/check-folder-docs.sh` (expected `folder-index: ok`). Never hand-edit it.
- Docs-only change: `./.claude/scripts/gates.sh fast`, and quote the `FACTORY_GATES:` line.
- Then open `index.html` in a browser at phone width and in dark mode and click through every page once.
**Traps:**
- Pages link real files only. `ls` a path before linking it. A file that does not exist yet is written as `<code class="missing">…</code>`, never a link. Link files, never folders (link the folder's `AGENTS.md` or `INDEX.md`).
- `BLOCKS.md` is the source of truth for block ids (B-01 to B-22 today). `blocks.html` and every other page follow it; never invent or renumber an id on a page.
- `references/*.md` are dated reviews of outside projects (Orca, agent-git, Nethera, OpenMuse, a security-audit skill), not endorsements and not instructions.
- Status chips (`data-state` with `data-proof`) are hand-maintained unless the page says otherwise. Nothing flips them yet; `scripts/check-sdlc-status.sh`, which would compare each chip with its proof, is proposed in the site spec and does not exist. When you land a block, flip its chip in the same pull request.
- Never type a present-tense count (open pull requests, checks, skills) into a page; state the date or point at a command. Never cite line numbers; point at a heading.
- No `<img>`, `<script>` or `<style>` in pages; never link `Reference-images/` or `docs/product/shots/iphone-settings.png`.
- Write pages with an editor tool, not a shell heredoc: the merge hook blocks shell commands that mention `.claude/` or `.agents/`.
- `intents/` (plural) is Stage 1. `intent/` (singular, at the root) is the local brain's catalogue and unrelated.
**SDLC stage:** all six — this folder teaches the lifecycle. Stage 1 itself lives in [intents/](../../intents/README.md).
**Map:** see [INDEX.md](INDEX.md) (generated by `python3 scripts/folder-index.py`; this folder has more than eight entries).
