# Chat search and resume

## How it was built

1. **Reference:** Chat Seek cloned read-only into `references/external/repos/chat-seek-vscode`
   (gitignored, never run).
2. **Understand** (workflow `wf_05400943-4ca`, 5 agents): four readers mapped Chat Seek's
   indexer/search, its UI and resume, the Laya model, and mesh's integration points, and a
   critic reconciled them. The findings that shaped the build:
   - 129 of 166 Codex rollouts on the Mac are subagent or reviewer threads.
   - Codex marks progress narration with `phase: commentary`, not the `channel` field Chat Seek
     filters on.
   - The indexable text is ~3.6 MB against 1.6 GB of raw transcripts.
   - 21 of 53 Claude sessions and 37 of 166 Codex sessions have a folder that no longer exists.
   - Laya is a 421M-parameter "System-1 decision model" (1.7 GB fp32 ONNX) used off-label as a
     reranker; purpose-built rerankers are 23–640 MB.
3. **Owner decisions (Arya, 2026-09-23):** keywords only, no reranker (a Jetson reranker if
   one is ever added); ship `/seek` for agents, approving the edit that raises
   `check-mesh-skills.sh` from 4 skills to 5.
4. **Build** (workflow `wf_c3e323c7-f29`, 6 agents): three builders on disjoint files (daemon
   + check, CLI, iOS), each followed by an adversarial reviewer. The reviewers found a
   whole-file restore that took RSS to 1.08 GB, duplicate restores on every resume,
   `resume-<first 8 hex>` names colliding for Codex (UUIDv7 timestamps), a 500 on an
   unreadable cwd, an index that never healed after a store rebuild, hostname-vs-hosts.json
   labels, and on iOS a 4xx retried on the next address so 409/410 never surfaced.
5. **Fix:** the daemon fixes were made by the orchestrator; the CLI and iOS fixes by workflow
   `wf_f0d30622-497`, each re-reviewed.

## What landed

- `install/payload/meshd/chats.ts` — FTS5 index of user/assistant text, streamed version by
  version from the session store; `GET /sessions/search` (federated); resume plans.
- `sessions.ts` — search and resume routes; a streamed, deterministic Claude restore.
- `mesh sessions search` / `mesh sessions resume`; `/seek` in the promoted `mesh-knowledge`
  skill.
- `iOS/ChatSearchView.swift` — Terminal → magnifying glass.
- `scripts/check-chat-search.sh`.
